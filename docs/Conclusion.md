# Conclusion

This project successfully demonstrates the implementation of Parallel Computing using Python Multiprocessing for prime number searching.

The experiment compared sequential and parallel execution approaches and measured their respective execution times.

The parallel implementation completed the task faster than the sequential implementation, reducing execution time from **1.5537 seconds** to **0.9973 seconds**.

A total of **41,538 prime numbers** were identified within the specified search range, and the experiment achieved a speedup of **1.56x**.

The results confirm that distributing workloads across multiple CPU cores can improve computational performance and reduce execution time for CPU-intensive tasks.

Therefore, Python Multiprocessing can be considered an effective approach for implementing parallel computing in computationally demanding applications.
