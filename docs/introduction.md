# Introduction

Parallel Computing is a computational approach that enables multiple tasks to be executed simultaneously using multiple processing units or CPU cores.

As modern computing problems become increasingly complex, parallel processing plays an important role in improving computational efficiency and reducing execution time.

Prime number searching is considered a computationally intensive task because each number must be evaluated individually to determine whether it is a prime number. As the search range increases, the amount of computation required also increases significantly.

This project implements Python Multiprocessing to perform prime number searching using both sequential and parallel approaches. The execution times of both methods are measured and compared to evaluate the performance improvement achieved through parallel processing.

The main objective of this project is to demonstrate the effectiveness of Parallel Computing and analyze the speedup obtained when workloads are distributed across multiple CPU cores.
